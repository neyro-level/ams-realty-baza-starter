# Historical evidence

Этот каталог хранит закрытые планы, их orchestration inventories и раннюю
архитектурную спецификацию. Файлы сохранены для аудита истории и не входят в
обычный active reading path.

- `plans/` — закрытые Master Plans №2–8; сохранённый внутри статус `APPROVED`
  описывает момент запуска, а не текущую очередь;
- `orchestration/` — их производные inventories;
- `architecture/` — historical v1.0 architecture snapshot.

Активные решения находятся в `docs/README.md` и перечисленных там Source of
Truth. Plan №8 завершён на SourceCraft `main@c5803cf`; итоговое evidence —
`../plan8/S8_25_FINAL_EXECUTION_REPORT.md`.
